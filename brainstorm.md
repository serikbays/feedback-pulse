# Brainstorming & Project Idea Session

## Project Name: MicroSaaS Analytics & Feedback Aggregator (FeedbackPulse)

### Concept:
FeedbackPulse — это нетривиальная платформа для разработчиков и основателей стартапов, которая агрегирует отзывы пользователей из различных источников и автоматически анализирует тональность, извлекает баги и запрашиваемые фичи с помощью AI.

### Core Features (MVP Scope):
1. **Projects Management**: Создание и управление проектами пользователей.
2. **Feedback Ingestion**: Добавление отзывов вручную или через API.
3. **Sentiment & Tag Analysis**: Автоматическое или имитированное присвоение тегов (`bug`, `feature_request`, `praise`) и оценок тональности (`positive`, `negative`, `neutral`).
4. **Dashboard & Metrics**: Отображение сводки метрик по отзывам и последним проблемам.
